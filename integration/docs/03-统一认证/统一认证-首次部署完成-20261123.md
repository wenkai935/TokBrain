## 一、部署前发现并修复的 4 个脚本 bug

| # | bug | 修复 |
|---|---|---|
| 1 | deploy/rollback 的 `systemctl restart/enable/stop/disable`、`cat >/etc/...` 缺 root | 全部改 `sudo -n` / `sudo tee`（已验证 `sudo -n true`=OK） |

| 5 | server.py 备份写在容器内，recreate 丢失，rollback 从宿主取不到 | 备份改落宿主 `$SRC/backups/`；并补做丢失的 server.py 原版备份（从 `music_server.py.from-nas` md5 `bf3b46e0`） |
