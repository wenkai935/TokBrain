### 为什么 provider 里那 62 处逻辑必须一起删

`hermes.py` 里电视逻辑不只是"电视功能"，它还是个**防吹牛守门员**：
检测到电视请求但模型没调 `mcp__tv_control__` 就强制丢弃回答并重试。
MCP 删了但守门员留着，模型会被逼着去调一个不存在的工具 → 答不出来或反复重试。
所以必须整块摘除，不能只删 MCP。

**保留的电视提及**（共 3 处，均为合理保留）：
- README 第 84 行"红外遥控的电视" —— 是米家里的物理设备，仍存在
- README 第 115 行"空调、窗帘、电视放进联动时需播报" —— 通用联动规则
- README 第 166 行"20 分钟电视声音里零误唤醒" —— 唤醒率测试描述，与电视助手无关
