# TokBrain 只读 MCP 服务（mcp_server/tokbrain_mcp.py）的独立运行环境。
#
# 必须装在**单独的 venv**（约定目录 .venv-mcp），不能装进主服务 .venv：
#   - mcp 2.3.x 要求 pydantic>=2.12、uvicorn>=0.31.1、starlette>=0.48；
#   - 主服务 requirements.txt 钉在 pydantic==2.9.2、uvicorn==0.30.6、starlette==1.3.1；
#   - 两套 pin 在同一环境里无法同时满足，因此主 venv 装完 requirements.txt 后
#     `pip check` 必然冲突。
# 拆开是刻意的：MCP 进程只读数据库、独立端口，与主服务进程完全隔离。
#
# 安装（二选一）：
#   1) 官方安装器：.\scripts\setup.ps1 -WithMcp
#   2) 手工：
#        py -3.12 -m venv .venv-mcp
#        .venv-mcp\Scripts\python.exe -m pip install --upgrade pip==25.2
#        .venv-mcp\Scripts\python.exe -m pip install -r requirements-mcp.txt
#        .venv-mcp\Scripts\python.exe -m pip check
#      启动：mcp_server\启动MCP服务.cmd
#
# 下列版本取自 2026-10-31 本机 .venv-mcp 实测可运行组合（MCP 服务已实际跑通）。
