## 2. bridge 读取飞书（标签携带）

来源：`Feishu._row_tuple`（bridge_feishu_obsidian.py:428-459）、`get_updated_rows`（:407-426）

| 飞书列 | 读取方式 | 携带去向 | 备注 |
|---|---|---|---|
| 标签 / 标签2 / 标签3 / 标签4 / 标签5 | `_text()` 逐列取文本 → 非空收集 | 合并为空格串（`" ".join(dict.fromkeys(tags))`） | **只用于占位笔记；不传给 TokBrain** |
| 链接 | `_text()` | `import_link(link)`（仅链接） | `import_link` 签名无 tags 参数（:159） |
| 最后修改时间 | 文本 | 增量游标 `last_modified_cursor` | 轮询过滤依据 |
| 处理状态 / work_id | 不读取 | — | 仅回写目标（镜像） |

⚠️ **关键缺口**：`confirm_batch(..., collection_id=None)` 支持把作品挂到 TokBrain 收藏夹，但 bridge 调用时**未传 collection_id**（:170, :898）——飞书标签与 TokBrain 的 `collections` 体系未打通。

## 3. 快轨占位笔记 → Obsidian（标签落点）

来源：`write_placeholder_note`（bridge_feishu_obsidian.py:712-748）

| 携带信息 | Obsidian 位置 | 示例 |
|---|---|---|
| 合并标签串 | 目录 `{VAULT_NOTES}/{首标签}/{record_id}.md` | `00收件箱/视频收藏/夹A/子夹B/recXXX.md` |
| 合并标签串 | frontmatter `tags: [...]` | `tags: [夹A/子夹B]` |
| 链接 | frontmatter `url` | — |
| record_id | frontmatter `feishu_record_id` | — |
| 状态 pending | frontmatter `status: pending` | — |

✅ **多级目录（2026-08-29 已实现）**：首标签含子级路径（如 `夹A/子夹B`，兼容 `\`）时，由 `_tag_to_dir()` 归一化为安全层级路径，`mkdir(parents=True)` 在收藏目录下**逐级自动新建缺失文件夹**；无标签回退 `_未分类`；非法字符（`<>:"|?*` 等）自动清理。

⚠️ `tags.split()` 按空格拆分（:710）：标签值若含空格会被拆成多个 tag。

## 4. 慢轨回填 → Obsidian 笔记（标签覆盖）

来源：TokBrain `obsidian_markdown`（summaries.py:257-283）+ bridge `backfill_note`

| 携带信息 | Obsidian 位置 | 说明 |
|---|---|---|
| work.collections（TokBrain 收藏夹名） | frontmatter `collections` | 来自后端 collections 表；✅ 2026-08-29 起由飞书标签映射创建并关联（方案 B） |
| row.tags（AI 总结关键词 ≤12） | frontmatter `tags` | 与飞书标签合并（飞书标签在前） |
| title / author / source / douyin_id / generated_at | frontmatter | manifest 自带 |
| feishu_record_id / url / status=processed / work_id / tokbrain_synced_at / tags | frontmatter | bridge 用 `merge_frontmatter` 追加/覆盖；**tags 由 `_merge_tag_list()` 合并飞书标签** |
| 关键帧 / 资产 | 附件硬链接 `![[...]]` | `gather_keyframes` + `hardlink_into_vault` |

✅ **已修复**：回填不再丢失飞书标签——`_merge_tag_list()` 把飞书标签前置合并（去重），最终 `tags: [收藏/未分类, ai关键词...]`。

## 5. 回写飞书（标签不参与）

来源：`writeback_feishu_status`（bridge_feishu_obsidian.py:979-1024）

| dispatch 状态 | 飞书「处理状态」列（select） | work_id 列 |
|---|---|---|
| pending | 待处理 | — |
| queued / processing | 处理中 | work_id（有值时） |
| processed | 已归档 | work_id |

仅状态变化时回写；跳过 `local-*`/`inbox-*` 来源；**标签列不回写**。
