## 1. `scripts/push_to_tokbrain.py` — 本地视频批量推送

### 命令行参数

| 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|
| `manifest`（位置参数） | 是 | — | 包含 `items` 与 `video_path` 的 JSON 清单文件路径 |
| `--token` | 否 | `TOKBRAIN_IMPORT_TOKEN` 环境变量 | 外部导入令牌（`data/integration_token.txt` 同源） |
| `--base-url` | 否 | `TOKBRAIN_API_URL` 或 `http://127.0.0.1:8001` | 本机 API 地址（仅允许 127.0.0.1/localhost） |
| `--idempotency-key` | 否 | 按清单内容自动生成 | 重试时复用，避免重复入库 |
| `--start-processing` | 否 | False | 提交后立即创建 AI 入库任务 |
| `--replace` | 否 | False | 替换未提交且内容不同的已上传资产 |
| `--timeout` | 否 | 120.0 | HTTP 超时（秒） |
| `--attest-rights` | 否 | False | **必须显式传入**，确认权利后才提交 |

### 清单 JSON 结构（manifest 文件）

```json
{
  "rights_attested": true,
  "items": [
    {
      "client_item_id": "必填，^[A-Za-z0-9][A-Za-z0-9._-]{0,99}$",
      "platform_work_id": "必填，纯数字抖音作品 ID",
      "title": "必填，1–500 字符",
      "video_path": "必填，本地视频绝对路径（仅本脚本读取，不会进 API）",
      "expected_sha256": "可选，与本地文件校验",
      "description": "可选",
      "author_id": "可选",
      "author_name": "可选",
      "published_at": "可选",
      "source_url": "可选",
      "duration_seconds": "可选",
      "target_collection_id": "可选",
      "extra_metadata": "可选，JSON 对象，≤64KB"
    }
  ]
}
```

> 限制：`items` 1–100 条；单视频 ≤1GB；清单 ≤2MB。`video_path` 只在本地消费，不入 API。

### 接收对象（后端接口）

| 调用 | 方法 | 路径 | 请求体 |
|------|------|------|--------|
| 创建批次 | POST | `/api/integrations/v1/import-batches` | 上述清单（含 rights_attested/items，`video_pending=true`，`expected_sha256=实际哈希`） |
| 上传资产 | PUT | `/api/integrations/v1/import-batches/{batch_id}/items/{client_item_id}/asset?replace=false` | `multipart/form-data`，字段名 `file` |
| 提交 | POST | `/api/integrations/v1/import-batches/{batch_id}/commit` | `{"start_processing": bool}` |

返回：`batch_id` / `items[]`（含 `upload_url`）/ `results[]`。

## 4. 入站 API `POST /api/integrations/v1/inbox/items`（P4 链路）

### 请求

| 项 | 值 |
|----|----|
| 鉴权 | `Authorization: Bearer <data/integration_token.txt>` |
| 头 | `Idempotency-Key`（必填，防重放） |
| Body | `application/json` |

```json
{
  "source": "douyin_share | local_text | ...",
  "rights_attested": true,
  "items": [
    { "link": "抖音分享链接", "title": "可选" }
  ]
}
```

### 规则

- `items` 1–100 条，>100 → 400 且零入库
- `rights_attested` 必须 true，否则 400
- 逐条规范化去重：`record_id=inbox-<sha256(规范URL)>`；digest 冲突 → 409；重放 → `replayed`
- 非法 URL：合法条仍入库（400 但部分已入队）

### 响应

```json
{ "accepted": n, "duplicates": n, "rejected": n, "items": [...], "replayed": n }
```

## 5. 补件 API `POST /api/library/works/{work_id}/supplement`

### 请求（multipart/form-data）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `rights_attested` | bool | 是 | 权利声明（前端固定 `"true"`） |
| `files` | file | 是 | 补件文件（图片 ≤12 个；视频 1 个） |

### 响应/状态码

| 码 | 场景 |
|----|------|
| 200 | 上传成功，返回 work + job 信息 |
| 404 | 作品不存在 |
| **409** | **该作品已在处理队列中**（`_active_job_for_work` 命中 queued/running/cancelling 的 ingest/summarize job） |
| 422 | 本地资产错误（如 size_mismatch） |
