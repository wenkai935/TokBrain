# TokBrain 原型设计说明

> **时效声明（2026-10-30 校订）**：原型文件都在 `prototypes/`（`tokbrain-prototype-v1/v2/v3.html` 等），**不再由 Next.js 前端托管**，也没有 `:3001/tokbrain-prototype-*.html` 这样的访问地址；双击文件用浏览器打开即可。本文是设计沿革记录，当前生产页面为「导入 / 解析 / 知识库 / 设置」四页签。

> 配套原型：`tokbrain-prototype-v1.html`（单文件零依赖、4 页 hash 路由 `#p1`~`#p4`）
> 定位：低保真、纯前端、刷新复位，用于评审与快速验证；支持 `?embed=1` 嵌入。
> 主题：暗色 token（背景 `#0d0b1a`、主色紫 `#8b7cf8`、解析橙 `#ff9f43`、完成绿 `#2ecc71`）

---

## 1. 页面总览

| 页面 | 核心板块 | 说明 |
|------|----------|------|
| p1 数据导入 | 数据统计 → 本地导入 → 网络视频（三端 Tab）→ 导入进度 | 三端统一选择界面，逐条视频进度卡片 |
| p2 解析 | **解析进度** → **模型配置**（左右拆分） | 本说明重点，见第 2、3 节 |
| p3 / p4 | 待入库 / 知识库等 | 不在本次改造范围 |

全局机制：`contenteditable` 文案 + `localStorage` + 编辑模式（`.editing` 类统一禁用交互，避免编辑与组件交互冲突）；暗色主题滚动条（紫渐变 webkit + Firefox `scrollbar-color`）。

## 2. 解析进度模块（p2 第一板块）

### 2.1 状态体系
- **单条预检状态标签**：可以确认（绿）/ 需补件（黄）/ 重复（紫）/ 失败（粉）/ 中断（青）
- **顶部统计卡（6 张）顺序**：重复 / 中断 / 失败 / 需补件 / 待分类 / 可确认；`left`（待分类）演示值 150 体现大队列感
- 早期 p1 导入沿用 5 态：待处理 / 解析中 / 待补件 / 已入库 / 失败

### 2.2 单条视频解析卡
```
[☑] 视频标题（超长省略）              [可以确认]
 ─────────●────────●────────●────────●──   ← 阶段进度条（橙色渐变填充）
   预检    音视分离   模型总结   标签分类        ← 文字在节点下方，不与进度条重合
 [本地]  作者待识别 · 96 秒 / 本地视频 · 完整处理
 ┌ 视频标签（左）────────────┐ ┌ 模型解析生成（右）────────┐
 │ 一级/二级/三级/四级标签 ↓   │ │ ● 短视频运营 × ● 内容创作 × │
 └────────────────────────────┘ └───────────────────────────┘
 删除预检结果
```

**阶段进度条设计要点**
- 结构：灰底轨道 `parse-timeline-track` + 橙色渐变填充 `parse-timeline-fill`（按阶段完成度算 `width%`）
- 4 关键节点圆，三态区分：
  - 已完成 → 绿色圆 + ✓
  - 当前工作态 → 白色圆 + **旋转 spinner**（`.parse-spin`，替代截图白色方块占位）
  - 待处理 → 灰色空心圆
- 橙色填充只到最后一个已完成节点；阶段文字置于节点下方（gap 8px），**确保文字与进度条不重合**
- 节点 `flex:1` 等分，轨道 `left/right:12.5%` 对齐首末节点圆心

### 2.3 标签区（左右布局）
- **左侧（知识库已有标签）**：4 个下拉框（一级 / 二级 / 三级 / 四级标签），来源 `KB_L1~KB_L4`
- **右侧（模型解析生成）**：绿色胶囊 chips（`.parse-tag-chip`，带 `×` 可删），最多 6 个，来源 `MODEL_TAGS`
- 左右以左边线分隔；暗色下拉（去原生箭头 + 内联 SVG caret + 深色 option）

### 2.4 分页与操作
- **分页制**：每页 5 条，底部分页栏 `< 1 2 3 >`，当前页高亮、首尾页箭头禁用
- 演示数据 12 条覆盖 `confirm/await/fail/stop/left` 多状态，默认 3 页
- **顶部 header 右侧**：紫色勾选 icon + 「确认加入待入库（n）」按钮 + 「选择全部可确认项」链接（已从底部操作栏上移）
- 非 `confirm` 态卡片隐藏标签区，当前阶段用旋转 spinner 表示正在工作

## 3. 模型配置模块（p2 第二板块）

- **左右拆分**（`.model-split`，`1fr 1fr` 中间竖线）：
  - 左栏「对话模型」、右栏「音频模型」
- 每栏顶部 `.model-col-header`：栏目标题 + 说明 + 「＋ 接入新模型」按钮
- **接入表单**：显示名 / 供应商 / 模型名 / API Base（双列）+ API Key（通栏，眼睛切换显隐）+ 启用开关 + 取消/保存
- **模型列表**：图标 + 名称·供应商 + 启用/停用标签 + 删除（二次确认）
- 已移除：平台免费模型卡片、萃点、平台付费说明（纯我的模型接入）

---

## 4. 导入进度模块（p1）

- 「导入进度」板块：双列视频进度卡片（`#p1-tasklist` grid 2 列，**奇数左多**），向下长度不限、无滚动条、空态最小区域
- 右上角 2 个纯图标按钮：说明（info，左）/ 刷新（refresh，右，0.6s 旋转）
- 说明弹层（`p1-help-mask`，p1/p2 共用）：5 态色说明 + 双列状态分布
- 进度以视频为最小单位逐条展示（`.vrow`：同色圆点 + 标题 + 状态色标签）

---

## 5. 关键设计约定

1. **速度优先**：单文件零依赖，复制板块时 ID 加 `p2-` 前缀避免冲突，函数参数化 `page` 复用
2. **编辑模式隔离**：`.editing` 下所有输入、按钮、下拉 `onclick/onchange` 自动禁用，仅保留 `data-k` 文案可编辑
3. **演示数据驱动**：`PARSE_DATA` / `NET_DATA` / `MODEL_DATA` / `AUDIO_MODEL_DATA` 等常量集中管理，覆盖各状态
4. **校验**：每次改动 `node --check` 校验内联 JS 语法，清理旧 CSS 类与旧 ID 残留引用
5. **网络视频三端统一**：抖音/小红书/B站 均采用「标签(收藏/喜欢/我的作品/观看历史/读取失败) + 子分类列表 + 视频网格 + 全选三态 + 同步」；无子分类时视频全宽
