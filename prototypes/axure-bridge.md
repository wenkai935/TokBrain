# Axure 接入说明（TokBrain 低保真原型）

> **时效声明（2026-10-30 校订）**：本文基于 v1 原型（含 `#p1`~`#p4` 与 `embed=1`）编写，属历史操作说明。原型文件均在 `prototypes/` 内、不再由前端托管；当前生产页面已改为「导入 / 解析 / 知识库 / 设置」四页签，若要把最新版原型接进 Axure，请以 `prototypes/tokbrain-prototype-v3.html` 为素材，本文的嵌入方法仍然适用。

## 一、结论：`.rp` 文件无法可靠产出

| 约束 | 说明 |
|---|---|
| 格式私有 | `.rp` 是 Axure 私有打包格式（内部为页面/元件树 JSON schema），未公开、随版本变化，官方无 SDK/CLI |
| 无法验证 | 当前机器未安装 Axure（注册表与常见安装路径均无匹配），生成后无法打开验证 |
| 硬凑风险高 | 结构不合法时 Axure 会提示「文件损坏 / 版本不兼容」，评审现场翻车成本高 |

> 如果最终**必须**交付 `.rp`，走下面的方案 B（PNG 底图描点）或方案 C（按元件清单手工搭建）。

---

## 二、方案 A（推荐）：Axure 内联框架嵌入 HTML

Axure 生成的原型本身就是 HTML，因此可以直接嵌入我们这套原型，评审时点击即可交互。

### 已做的改造
`tokbrain-prototype-v1.html` 新增两项能力：

| 能力 | 用法 |
|---|---|
| **hash 路由** | `#p1` 导入 · `#p2` 解析 · `#p3` 知识库 · `#p4` 设置 |
| **嵌入模式** | 加 `?embed=1` 或 `#...&embed=1`，隐藏原型自带的顶部工具栏与左侧导航，只保留页面内容（由 Axure 提供导航） |

示例 URL：
```
tokbrain-prototype-v1.html#p1               # 导入页（完整框架）
tokbrain-prototype-v1.html#p2&embed=1       # 解析页（嵌入模式）
tokbrain-prototype-v1.html#p3&embed=1       # 知识库页（嵌入模式）
tokbrain-prototype-v1.html#p4&embed=1       # 设置页（嵌入模式）
```

### Axure 端搭建步骤

1. **新建工程** → 站点地图建 4 个页面：
   `01_导入` / `02_解析` / `03_知识库` / `04_设置`

2. **拖入内联框架**（元件库 → Inline Frame，Axure 10 在「高级」分组）
   - 尺寸建议：`1200 × 760`
   - 位置：页面左侧留出 `160px` 放你自己的导航条

3. **设置链接**（双击内联框架）
   - 选择「链接到 URL 或文件」
   - 填入：
     - `01_导入` → `tokbrain-prototype-v1.html#p1&embed=1`
     - `02_解析` → `tokbrain-prototype-v1.html#p2&embed=1`
     - `03_知识库` → `tokbrain-prototype-v1.html#p3&embed=1`
     - `04_设置` → `tokbrain-prototype-v1.html#p4&embed=1`

4. **样式设置**
   - 内联框架：边框设为「无」，勾选「隐藏边框」
   - 滚动条：Axure 内联框架默认自适应滚动，内容较长时会出滚动条，无需额外设置

5. **自己搭导航**
   - 在每页左侧放 4 个矩形作为 Tab，设置「鼠标单击 → 打开链接 → 链接到页面」
   - 选中态用「选中」交互样式（填充 `#eaf1ff`，文字 `#2a5cd0`）

### 路径注意事项（重要）

| 场景 | 做法 |
|---|---|
| **本地 F5 预览** | Axure 生成的临时目录不含我们的 HTML，需先填**本地绝对路径**（如 `D:/code/TokBrain-main/prototypes/tokbrain-prototype-v1.html#p1&embed=1`），仅用于自测 |
| **发布到本地文件夹** | 「发布 → 生成 HTML 文件」→ 把 `tokbrain-prototype-v1.html` 复制到生成的目录**同级** → 内联框架改填**相对路径** |
| **发布到 Axure Cloud** | 内联框架只能填绝对 URL，需先把 HTML 托管到外网（GitHub Pages / 内网静态服务），否则评审端打不开 |

## 三、方案 B：PNG 底图描点（最终必须交付 `.rp` 时选这个）

1. 打开 `tokbrain-prototype-v1.html`，用浏览器打印（`Ctrl+P`）逐页导出 PDF
   - 打印时工具栏/侧边导航会自动隐藏（已内置 `@media print`）
2. PDF 转 PNG（300dpi）→ 在 Axure 里作为**页面底图**导入
3. 在底图上用「热区 Hot Spot」圈出可点区域，添加跳转交互
4. 优点：100% 产出 `.rp`；缺点：内容不可编辑，改版需重新出图

## 五、方案 D：实验性生成 `.rp`（不推荐）

可以试，但需你先安装 Axure 再验证，存在以下风险：
- 生成的 `.rp` 可能提示文件损坏
- 即使打开，元件样式/交互可能错乱
- 调试成本高于方案 A 的搭建成本

**不建议在评审前使用。**
