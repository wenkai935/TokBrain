# 主题环境资产生成说明

> **时效声明（2026-10-30 校订）**：主题现为 **4 套**（`aura` / `sunset-cloudsea` / `eastern-mist` / `ocean-dawn`），清单以 `registry.ts` 为准；本文的生成约束对每一套均适用。

这些背景由内置图像生成工具根据用户提供的参考图和主题提示词创建。最终文件位于 `frontend/public/themes/`。

所有生成请求共用以下约束：

- 用途：响应式 Web 应用主题环境背景。
- 构图：16:9 横向，中央为低对比内容安全区，细节集中在外缘。
- 只生成环境；移除并禁止 UI、面板、卡片、图表、文字、数字、品牌、人物和水印。
- 背景必须能承载真实 HTML/CSS，不将参考图中的界面烘焙进图片。

## 每套资产的最终场景提示

- `ocean-dawn.webp`：清晨海岸、蓝绿色海水、薄雾、远处悬崖与右上日出；禁止水下世界、度假广告和大面积眩光。
- `sunset-cloudsea.webp`：金橙地平线、玫瑰云层、深紫暮色与远山剪影；禁止巨型太阳、过饱和橙色和旅游海报感。
- `eastern-mist.webp`：现代宣纸留白、灰绿层峦、雾、远瀑与松树；禁止宫殿、书法、红灯笼和仿古画卷。
